🔑 Claude API 키

키 받는 방법

  1. console.anthropic.com 에 가입·로그인
  2. 왼쪽 메뉴 Billing 에서 크레딧 충전 (꿈 분석 1번에 대략 수십 원)
  3. API Keys → Create Key → 나온 키를 복사해서 위 칸에 붙여 넣고 저장

키와 꿈 일기는 이 컴퓨터의 dream-detective\data 폴더에만 저장돼요. 분석할 때만 꿈 내용이 Claude 로 보내져요.
