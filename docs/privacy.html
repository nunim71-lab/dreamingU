🔒 내 꿈은 어디에 저장되나요?

꿈꾸는부엉이 개인정보 안내 · 2026년 11월

한 줄 요약

꿈꾸는부엉이에는 회원가입도, 꿈을 모아 두는 서버도 없어요. 꿈 일기는 내 기기 안에만 저장되고, 내가 버튼을 누를 때만 정해진 곳(Claude, 내 깃허브)으로 보내져요. 앱을 만든 사람도 내 꿈을 볼 수 없어요.

📱 내 기기 안에 저장되는 것

  • 꿈 내용, 꿈꾼 시간·장소, 꿈속 기분, 요즘의 일
  • 별자리 차트, 부엉이의 풀이(수사 보고서), 나의 메모, 종합 분석
  • 설정: 기본 장소, (넣었다면) Claude API 키, (켰다면) 자동 동기화 정보

휴대폰·인터넷 주소로 쓰면 그 브라우저 안에, 컴퓨터 프로그램으로 쓰면 꿈꾸는부엉이 폴더 안 data 폴더에 저장돼요.

⚠️ 브라우저의 "사이트 데이터 삭제"를 하거나 앱을 지우면 함께 지워질 수 있어요. ⚙️ 설정 → 📤 꿈 일기 내보내기로 가끔 백업해 두세요.

🔑 API 키 · 깃허브 열쇠
