# 꿈탐정 부엉 🦉🔍

> 황금 망토를 두른 신비로운 하얀 부엉이, 꿈탐정 부엉이 간밤의 꿈 사건을 수사해 드려요

꿈을 적으면

1. **꿈꾼 순간의 별자리 차트**(행성 10개, 상승점·중천점, 달의 모양, 각도)를 바로 그려 주고, **간단한 하늘 풀이**(달의 별자리, 달 모양, 주요 각도 등)도 곁들이고
2. **Claude(AI)** 가 쉬운 문장으로 **🌗 분석심리학 풀이**(융의 눈으로 본 마음)와 **🔮 천궁도 풀이**(꿈꾼 순간의 하늘과 꿈)를 따로따로 써 주고
3. **꿈 일기**에 차곡차곡 모아서
4. **자주 꾸는 꿈의 단서**(되풀이되는 상징, 기분, 달의 별자리)를 보여 주고, 부엉 탐정이 **종합 분석**도 해 줘요.

받는 곳: <https://github.com/nunim71-lab/dreamingU>

> 꿈 해석은 마음을 비추는 거울일 뿐, 예언이나 진단이 아니에요.

---

## 윈도우에서 시작하기

1. Node.js 가 없다면 <https://nodejs.org> 에서 **LTS** 버전을 설치합니다. (재잘이를 쓰고 있다면 이미 있어요)
2. <https://github.com/nunim71-lab/dreamingU> 에서 초록색 **[Code] → Download ZIP** 을 눌러 받고, 압축을 풀어 원하는 곳(예: 문서 폴더)에 둡니다.
3. 그 폴더의 **`start.bat`** 을 더블클릭합니다. (경고 창이 뜨면 **추가 정보 → 실행**)
4. 검은 창이 뜨고 크롬에 꿈탐정 화면이 열려요. **검은 창은 닫지 마세요.** 닫으면 꺼져요.
5. **바탕화면 바로가기:** `make-shortcut` 을 더블클릭하면 바탕화면에 하얀 부엉이 아이콘 **[꿈탐정]** 이 생겨요.

재잘이와 동시에 켜도 괜찮아요. (재잘이는 3000번, 꿈탐정은 3100번 주소를 써요)

## 처음 한 번만: Claude API 키 넣기

꿈 분석은 Claude 가 해요. 그래서 **Claude API 키**가 필요해요. (차트 그리기와 꿈 일기는 키 없이도 돼요)

1. <https://console.anthropic.com> 에 가입하고 로그인합니다.
2. 왼쪽 메뉴 **Billing** 에서 크레딧을 충전합니다. (꿈 분석 1번에 대략 수십 원 정도. 5달러면 꽤 오래 써요)
3. **API Keys → Create Key** 를 눌러 키를 만들고 복사합니다. (`sk-ant-` 로 시작해요. 이 키는 비밀번호처럼 남에게 보여 주지 마세요)
4. 꿈탐정 화면의 **⚙️ 설정** 에 붙여 넣고 **저장** 을 누르면 끝!

## 쓰는 법

- **✍️ 꿈 기록**: 꿈 내용, 꿈꾼 시간(대충 깬 시각), 장소, 꿈속 기분을 넣고 **[🔍 부엉 탐정에게 맡기기]**. 부엉 탐정이 1분쯤 수사 보고서(🌗 분석심리학 풀이 + 🔮 천궁도 풀이)를 써 줘요.
  "요즘 깨어 있을 때의 일" 칸에 요즘 상황을 적으면 해석이 훨씬 깊어져요.
- **📔 꿈 일기**: 지금까지의 꿈. 누르면 차트와 보고서를 다시 볼 수 있고, 다시 분석하거나 지울 수 있어요.
- **🔁 꿈 패턴**: 자주 나온 상징·기분·달의 별자리를 막대그래프로. **[종합 분석]** 을 누르면 부엉 탐정이 꿈 전체의 흐름을 읽어 줘요.
- **⚙️ 설정**: API 키, 기본 장소와 시간대.

## 내 꿈은 어디에 저장되나요?

- 꿈 일기와 API 키는 **이 컴퓨터의 꿈탐정 폴더 안 `data` 폴더**에만 저장돼요. 인터넷이나 깃허브에 올라가지 않아요.
- 분석을 누를 때만 꿈 내용과 차트가 Claude(Anthropic)로 보내져요.
- 다른 컴퓨터로 옮기거나 새 버전을 받을 때는 `data` 폴더를 통째로 복사해 새 폴더에 넣으면 꿈 일기가 그대로 이어져요.

## 별자리 차트에 대해

- 행성 위치는 앱이 직접 계산해요 (외부 서비스 없이). 오차는 1° 안쪽이라 별자리와 각도를 보기엔 충분해요.
- 서양 점성술 방식(회귀 황도대), 하우스는 상승점에서 30°씩 나누는 **이퀄 하우스** 예요.
- 시간대는 기본이 한국(UTC+9)이에요. 해외에서 꾼 꿈이면 장소를 "직접 입력", 시간대를 바꿔 주세요.

## 개발용

- 실행: `npm start` (이 폴더에서), 테스트: `npm test`
- 외부 라이브러리 없이 Node.js 내장 기능만 써요. 아이콘 다시 그리기: `python3 tools/make-icon.py tools/icon.ico public/icon.png` (Pillow 필요)
- 분석 모델은 `claude-opus-5-5`. `data/settings.json` 의 `"model"` 로 바꿀 수 있어요.
